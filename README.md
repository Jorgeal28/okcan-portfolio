# OKCAN – cómo subir un proyecto nuevo (para Nacho)

1. Entra al repo en github.com → carpeta `projects`.
2. `Add file` → `Upload files`. Arrastra una **carpeta nueva** con las imágenes.
   - Nombre de carpeta: `03-nombre-del-proyecto` (el número manda el orden; el nombre es el título).
   - Imágenes: `01.jpg`, `02.jpg`, `03.jpg`… (ese orden es el de la web; la 01 es la portada).
3. `Commit changes`. En ~1-2 minutos aparece en la web. No hay que tocar código.

Límites: máx. 100 archivos por subida desde el navegador, 25 MB por archivo (web de GitHub). Repo cómodo hasta ~1 GB.

## Puesta en marcha (solo una vez, Jorge)
- Repo en GitHub con estos archivos (`index.html`, `scripts/`, `.github/`, `projects/`).
- Settings → Pages → Source: **GitHub Actions**.
- Dominio okcancreative.com: Settings → Pages → Custom domain.
